# Support

This is a public companion repository for a Pluralsight Author Talk. It is provided as-is for educational reference. The maintainer offers best-effort support but cannot guarantee response times.

## Where to ask what

| Question type | Best channel |
|---|---|
| "How do I use Skill / agent / prompt X from this repo?" | [Discussions](../../discussions) — Q&A category. |
| "I found a bug." | [Open an issue](../../issues/new/choose) using the **Bug report** template. |
| "I want this repo to do something it doesn't." | [Open an issue](../../issues/new/choose) using the **Feature request** template. |
| "I found a real security vulnerability." | See [`SECURITY.md`](./SECURITY.md). Do **not** open a public issue. |
| "I want to take a deeper Pluralsight course on this topic." | [Tim's author page](https://app.pluralsight.com/profile/author/tim-warner). |
| "I want to hire Tim for a talk or workshop." | [TechTrainerTim.com](https://techtrainertim.com). |

## What this repo is NOT

- A supported product.
- A production-ready application. The Skill Path Picker is intentionally minimal — no backend, no persistence beyond `sessionStorage`, no authentication.
- A reference for every possible AI agent pattern. It demonstrates the patterns covered in one 60-minute talk.

## What you'll get

- A best-effort answer on Discussions within a week.
- Acknowledgment on issues within two weeks.
- A merged fix when a community member opens a PR that meets the [contribution standards](./CONTRIBUTING.md).
